## 3. Test grammatical person before rewriting anything

Bodies are third person ("He is not a loud man"). Suspicion: third person
invites narration (the 20-characters-of-prose failure), second/first person
gets inhabited. Run the KRONSCH completion test on one agent in both forms
before converting any.
